

\# TI AP Physics Python Programs



A collection of Python programs for any of the TI calculators with support python, designed to help students with AP Physics 1 calculations.



\## Programs



| Program | Description | Status |

|---|---|---|

| KINEM | Constant-acceleration kinematics | Available |

| FORCE | Newton's laws and net force | Planned |

| FRICT | Kinetic friction | Planned |

| ENERGY | Work, energy, and power | Planned |

| MOMENT | Momentum and impulse | Planned |

| CIRC | Circular motion | Planned |

| PROJ | Projectile motion | Planned |



\## Getting Started



1\. Check that the code is compatible with your calculator.

2\. Open a program's `.py` file to view its source code.

3\. Transfer the program using a supported TI calculator workflow.

4\. Test the program with known values before relying on its results.



\## Units



Unless stated otherwise, programs use SI(international system of units) units:



\- Distance: meters (m)

\- Time: seconds (s)

\- Velocity: meters per second (m/s)

\- Acceleration: meters per second squared (m/s^2)

\- Mass: kilograms (kg)

\- Force: newtons (N)

\- Energy: joules (J)
